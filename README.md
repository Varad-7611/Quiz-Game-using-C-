# 🧠 Quiz Game using C++

This project is a **simple console-based Quiz Game** developed in **C++**.  
The game presents multiple-choice questions to the user, accepts their input, checks the answers, and keeps track of the score.

It’s a fun way to test general knowledge or create custom quizzes, and a great beginner-friendly project to understand **conditionals, loops, and file handling** in C++.

---

## 🎮 Features

- 📋 Multiple-choice questions
- ✅ Answer validation and scoring
- 🧾 Display of final score at the end
- 🔁 Option to replay the quiz
- 📦 Easy to modify questions (can be hardcoded or read from a file)

---

## 🚀 How to Run

1. **Clone or download the project** to your system.
2. **Compile the code** using a C++ compiler (like `g++`):

```bash
g++ quiz_game.cpp -o quiz_game
